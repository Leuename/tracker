# Create Feature

## Applicability

Gated; feature implementation is outside the documentation-only phase.

## Prerequisite State

No editable app source, package workflow, tests, backend, or authoritative generated-output pipeline exists.

## Workflow

Record the requested outcome, map affected artifact classes, identify missing source and acceptance criteria, and request explicit implementation authorization.

## Stop Condition

Stop immediately before editing exports, scaffolding an app, adding dependencies, or inventing commands.

## Deliverable

A blocked-status brief listing evidence, missing prerequisites, acceptance questions, and the smallest activation gate.

- **AGENT-03** makes this command stop when the documentation-only scope is still active.
