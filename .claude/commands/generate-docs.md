# Generate Documentation

## Applicability

Usable now to create or update repository knowledge.

## Prerequisite State

Canonical evidence, decisions, handoff, root/scoped guides, and specialized adapters exist.

## Workflow

Update the canonical owner of each fact; keep observations separate from decisions; add upward and related links; scan hidden Markdown; validate local links, placeholders, and contradictions; update the handoff.

## Stop Condition

Stop before documenting guesses as facts, duplicating central policy, editing `.obsidian`, or changing non-Markdown files.

## Deliverable

Changed note list, new semantic relationships, validation counts, and unresolved evidence gaps.

Parent: [AI Agent Context](../../docs/AI%20Agent%20Context.md) · Decision basis: [Decisions](../../docs/Decisions.md) · Related: [workflow](../skills/documentation/SKILL.md)

## Guideline Basis

- **MD-01** gives generated documentation a concise heading hierarchy.
- **MD-02** requires descriptive links and a local-resolution check.
- **MD-03** keeps lists, tables, spacing, and code fences render-safe.
- **MD-04** updates canonical notes instead of creating duplicate facts.
