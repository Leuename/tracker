# Release

## Applicability

Not applicable: no versioning, changelog, CI, release pipeline, or verified build artifact exists.

## Prerequisite State

Root ZIP/PDF and export files are references, not evidence of a repeatable release process.

## Workflow

Identify proposed deliverables, provenance, version owner, validation, approval, and distribution requirements.

## Stop Condition

Stop before tagging, packaging, uploading, or describing an unverified release as complete.

## Deliverable

A release-readiness checklist with blockers and evidence owners.

Parent: [AI Agent Context](../../docs/AI%20Agent%20Context.md) · Decision basis: [Decisions](../../docs/Decisions.md) · Related: [workflow](../rules/git-workflow.md)

## Guideline Basis

- **GIT-01** requires a focused, reviewable release change set.
- **GIT-02** defers commit-message convention until repository history and branch policy exist.
- **GIT-04** requires version, artifact, deployment, and rollback traceability.
- **PG-02** blocks release commands while no package or release configuration exists.
