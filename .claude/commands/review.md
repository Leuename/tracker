# Review

## Applicability

Usable now for documentation and passive artifact review.

## Prerequisite State

Markdown and static exports exist; generated boundaries and external active content are documented.

## Workflow

Read the nearest guide, define review scope, compare claims with canonical evidence, inspect only necessary artifacts, validate links/scope, and report findings before summary.

## Stop Condition

Stop before fixes, active-content execution, or source-dependent conclusions.

## Deliverable

A severity-ranked review with exact paths, evidence, checks, and residual risks.

Parent: [AI Agent Context](../../docs/AI%20Agent%20Context.md) · Decision basis: [Decisions](../../docs/Decisions.md) · Related: [workflow](../agents/code-reviewer.md)

## Guideline Basis

- **PG-04** structures review findings around exact evidence, impact, and verification.
- **GIT-01** limits review to the requested logical change and identifies unrelated edits.
- **SEC-03** requires secrets and sensitive payloads to be redacted from review output.
