# UX Review

## Applicability

Usable now for passive review of exported CRM screens; browser execution needs explicit authorization.

## Prerequisite State

Static `.dc.html` screens provide visual structure but not verified interactions, research, or analytics.

## Workflow

Select screens, inspect hierarchy, navigation, terminology, forms, states, consistency, responsive clues, and accessibility overlap. Cite artifacts and label behavior assumptions.

## Stop Condition

Stop before executing untrusted HTML, editing exports, or claiming observed user behavior.

## Deliverable

A screen-indexed, severity-ranked UX report with assumptions, evidence paths, and source-level recommendations.

- **WCAG-01** frames static visual observations without claiming full conformance.
