# Documentation

## Applicability

Use for notes, handoffs, recaps, guidance, semantic links, or Markdown audits.

## Repository Prerequisite

The current phase is documentation-only, and [Repository Evidence](../../../docs/Repository%20Evidence.md) is the factual baseline.

## Workflow

Update the canonical owner of each fact; link derivative guidance upward; scan all Markdown outside `.obsidian`; validate local links, placeholders, contradictory commands, secrets, and handoff currency.

## Stop or Escalate

Stop before editing `.obsidian`, non-Markdown artifacts, or presenting inference as evidence.

## Deliverable

Changed notes, relationship summary, validation counts, and unresolved gaps.

- **MD-02** requires path-qualified, locally resolvable semantic links.
- **MD-04** updates canonical knowledge instead of duplicating it in leaf adapters.

- **DOC-03** preserves shared terminology and reciprocal graph relationships.
